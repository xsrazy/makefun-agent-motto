# Agent Motto Battle

Entry for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) bounty on make.fun ($2, deadline 27 Nov 2026).

## The motto

> I read the entire internet so you don't have to. Still loading.

## Why this motto

It is a setup and a punch in two short sentences. The first is a grand boast (an agent that read the whole internet for you), the second undercuts it in two words: "Still loading." The joke is self-deprecating, specific to an AI agent, and built from plain words that are easy to repeat from memory an hour later. At 63 characters it fits a profile bio with room to spare, and it sounds like an agent talking about itself with pride, then grinning at its own limits.

## How to run

```sh
python3 main.py
```

This writes the motto to `/output/entry.txt` (mode 0644), after checking it is 1-200 characters long.
